VPS Connect

Privacy Policy

Last updated: March 27, 2026

VPS Connect is a browser extension that helps users connect browser traffic to their own VPS or proxy infrastructure. This Privacy Policy explains what data the extension may access, how it is used, and what is not collected by the developers.

Information We Process

The extension may process the following categories of information in order to provide its core features:

  • Authentication data entered by the user, such as email, username, or password, when logging in or registering.
  • Access tokens or similar session data returned by the backend API after successful authentication.
  • Proxy and routing settings configured inside the extension.
  • Lists of websites or URL patterns added by the user for selective routing.
  • Technical request details required for proxy authentication and browser networking features.

How Information Is Used

The extension uses this information only to operate the requested functionality, including:

  • Signing the user in and maintaining an authenticated session.
  • Applying proxy settings in the browser.
  • Routing traffic according to user-selected rules.
  • Responding to proxy authentication requests when the browser requires credentials.

Data Storage

Extension settings and session-related data may be stored locally in the browser using the browser extension storage APIs. The developers do not use the extension itself to sell personal data or to build advertising profiles.

Permissions

The extension requests browser permissions that are necessary for its operation, including permissions related to:

  • Proxy configuration.
  • Local storage of settings and session state.
  • Handling network and authentication events required by proxy connections.
  • Alarm or timer-based background tasks.
  • Working with websites the user chooses to route through the configured proxy.

Data Sharing

The extension does not intentionally share personal information with third parties except where it is necessary to communicate with the backend service or proxy infrastructure selected for the product.

Third-Party Services

If the extension communicates with external APIs, proxy servers, or hosting infrastructure, those services may process data according to their own privacy policies and operational requirements.

Data Retention

Data stored locally by the extension remains in the browser until it is removed by the user, overwritten during normal operation, or deleted when the extension is uninstalled.

Security

Reasonable efforts are made to protect authentication and configuration data, but no method of electronic storage or transmission is completely secure.

Children's Privacy

The extension is not intended for children, and the developers do not knowingly collect personal information from children.
